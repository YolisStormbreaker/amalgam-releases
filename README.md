# Amalgam releases

Public downloads of Amalgam, a VPN client over olcRTC.

- macOS: signed and notarized builds for Apple silicon, delivered by Sparkle from the feed at
  https://updates.yolisstorm.com/amalgam/appcast.xml. The archives live in the `files` release.
- Android: signed APKs (arm64), offered by the app itself from the feed at
  https://updates.yolisstorm.com/amalgam/android.json; the same `files` release holds them. The
  first install is by hand (allow installs from your browser or file manager); later updates come
  from the app. Package `com.yolisstorm.amalgam`.
